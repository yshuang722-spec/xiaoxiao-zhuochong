小小桌宠 v1.0.5 更新包使用说明

适用于官方 Windows v1.0.3、v1.0.4，也可重复运行以检查是否已经更新。

操作步骤
1. 下载 xiaoxiao-zhuochong-1.0.5-update.zip，右键“全部解压”。
2. 从托盘菜单选择“退出全部桌宠”。只关闭控制页窗口不会退出程序。
3. 打开解压后的更新包文件夹，双击 update.cmd。
4. 选择原来“小小桌宠.exe”所在文件夹，目录内应有 resources 和 runtimes。不要选择更新包目录或角色目录。
5. 等待提示“更新完成”，然后使用原来的快捷方式启动。
6. 打开控制页，开启想使用的角色。新加入的奶茶千金默认隐藏。

常见问题
- 更新包不能单独启动桌宠；新用户请下载完整客户端。
- 程序文件与支持的版本不匹配：检查所选目录是否正确。自改过的程序文件不会被强行覆盖。
- 提示校验失败：重新下载并完整解压更新包，不要手工乱拷 payload 文件夹。
- 更新时出错：保留错误信息与备份；写入失败会尝试自动回滚。
- 更新后仍旧：确认快捷方式指向刚更新的那一份客户端。

本包更新六个角色、167段已收录动作及当前客户端程序。已有位置、大小、显示状态、分身、自定义动作及自定义人设会保留；同名官方动画更新为本版。
备份位于 %LOCALAPPDATA%\XiaoXiaoZhuoChong\UpdateBackups。
自定义过DSH_HOME的用户，应在相同环境运行，或用 update.ps1 的 -ProgramDir 和 -DataHome 指定原目录。
