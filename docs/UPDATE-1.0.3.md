# v1.0.3：三角色动画与碰撞更新

本次以v1.0.2公开版本为基础，选择性合入这些内容：

- 橙毛大小姐：16段官方动画，补齐送情书；送情书首帧对齐当前待机，保留信封特写。你号没了改用较保守的VP9编码。
- 黄毛该溜子：7段官方动画，补齐哈哈大笑与小汽车。
- 白毛小龙娘：从空模板升级为可用角色，共8段动画：待机观望、扑腾小翅膀、被大肥鱼骑、傲娇表情、挥手打招呼、高兴飞起、提裙转圈、喷火冒烟。
- 独立角色进程之间可传递碰撞和反弹；沿用原有拖拽抛掷。静止重叠、正在拖动或打开菜单的角色不会被主动弹开。碰撞盒是固定主体范围，不随翅膀、火焰、汽车或特写逐帧改变。
- 新1280×960画幅适配，旧画幅保持兼容。
- 解码错误、持续6秒无进度、遗漏结束事件会恢复到待机；旧请求回调失效，不再覆盖新播放。仅恢复出错角色，不重启其他人物。

**黑毛小狐狸不在本次发布中**，不会复制或删除其用户数据。蓝毛小女仆素材保持v1.0.2原样，公用播放器和碰撞代码随版本升级。没有合入开发中的完整角色日志系统或其他未列明的开发进度。

## 已下载v1.0.2的用户

下载本次Release的`xiaoxiao-zhuochong-1.0.3-update-from-1.0.2.zip`，完整解压，双击`update.cmd`，选择**原程序的小小桌宠.exe所在文件夹**。

更新器校验文件、正常退出所选客户端、备份并更新。完成后继续用原快捷方式启动。无需重新下载Electron/Node或整个客户端；无需安装Python/npm。

三个角色的官方同名文件会替换到本版本；保留已有角色的位置、大小、显示状态和自定义动作。旧白毛空模板也能升级。新增白毛默认隐藏，请在控制页开启。自定义`DSH_HOME`可通过`update.ps1 -ProgramDir 路径 -DataHome 路径`指定。

更新器仅接受已知v1.0.2或本更新包文件；遇到其他开发版本会停止。写入失败自动回滚。备份位于`%LOCALAPPDATA%\XiaoXiaoZhuoChong\UpdateBackups`。更新包包含三位的完整官方动作，防止用户旧目录缺素材，所以并非只有几KB的小补丁。

## 新用户

先下载v1.0.2解压即用基础包，再运行本次更新包。GitHub自动生成的Source code压缩包是开发源码，不是含Electron/Node的运行包。

## 验证与边界

- 在Windows PowerShell 5.1的隔离目录执行实际升级、预检查、重复更新、保留个人设置、自定义动作、白毛模板升级和小狐狸目录保持不变；故障注入后逐文件核对回滚一致；损坏包和未知客户端版本会在写入前被拒绝。
- 碰撞测试覆盖动量传递、相互弹开、快速穿过检测、拖拽保护、重复碰撞节流，以及两个独立系统进程的通信和一方退出后的另一方继续连接。
- 基于实际`switchTo`路径验证：旧播放器在加载后发生解码错误会停住；新版恢复待机。正常推进、菜单暂停、旧代次回调不会误触发恢复。
- 本机实际桌宠：“你号没了”兼容转码后连续3次完整播放；送情书优化后完整播放并回到待机。送情书193帧逐帧检查无新增裁切，大小、中心和脚底与待机的首帧测量差异低于0.3个屏幕像素（角色尺寸462）。
- 旧日志确认了`PIPELINE_ERROR_DECODE`，但不同解码器和并发环境下的所有触发条件尚未完全确定。恢复机制避免永久停滞，不等于保证所有视频从此不会解码失败。有限次本机通过不代表所有Windows设备均已验收。
