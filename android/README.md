# 小小桌宠 安卓手机版 v0.3.1

## 安装与使用
1. 下载 APK，打开后按手机提示安装。已有版本直接覆盖安装，不要先卸载。
2. 打开应用，在设置→手机权限中允许悬浮显示；按需要允许通知和后台运行。
3. 点击角色的显示，返回手机桌面查看角色。慢拖改变位置，快速甩动可以弹跳；设置→弹动与碰撞可分别开关。
4. 长按桌面角色可选择对话、动作、大小或隐藏。应用内点击对话查看聊天记录；管理→角色资料可修改名字和人设。
5. 设置→AI接口设置填写服务地址、模型和密钥。各角色共用接口，分别保留聊天记录和人设。
6. 外观支持日间、夜间和跟随系统。点击首页Logo可快捷切换。

## 本版内容
包含蓝毛小女仆、橙毛大小姐、黄毛该溜子、白毛小龙娘、黑毛小狐狸、奶茶千金六个角色，共167段视频。补齐新增动作，更新奶茶千金温柔富有的大姐姐人设；桌面对话角色名顶部居中，当前问题移到输入框上方。

## 常见问题
- 角色不出现：检查悬浮权限并离开应用主页；主页前台时暂时收起桌面角色。
- 后台停止：在手机系统设置允许后台运行；不同手机入口有所区别。
- 覆盖安装失败：确认是同一应用来源和签名，不要为安装而卸载旧版，以免丢失记录。
- AI无法回复：检查地址、模型、密钥和网络；接口费用由服务商决定。

## 本地界面与边缘收起调整
- 将角色持续拖向屏幕左侧或右侧，到达边缘继续拖住片刻或松手后自动收起。点击边缘入口先展开，再次点击才恢复角色；展开四秒未确认会自动收回。每个角色和分身独立保存收起状态。
- 收起时暂停该角色视频、退出碰撞；全部隐藏仍会隐藏边缘入口。应用内管理可恢复已收起的角色。
- 桌面对话保留顶部角色名，不显示关闭按钮，点击面板外空白处退出；当前问题字号14sp，位于输入框上方。
- 主界面使用日夜柔和背景，玻璃面板减轻底色并增加内外高光；不支持系统模糊时使用实色降级。

- 动作面板选中动作后继续保留，可连续选择其他动作，点击关闭后退出。
- 菜单采用明显的缩放弹簧入场、缩小淡出、按钮按压回弹；尊重系统动画关闭设置。

- 边缘收起增加460毫秒向外滑动、缩小淡出过渡，完成后显示边缘入口。入口展开后点击桌面其他位置立即缩回，并重置第二次确认；四秒超时收回仍保留。

- 应用内聊天记录相邻发言仅换行，角色回复前添加向右箭头；桌面气泡保持原有纯文字样式。仅改变显示，不改写历史内容。

- 长按0.4秒打开角色菜单；非对话模式的普通回复气泡10秒后消失。对话模式气泡持续保留，点输入面板外部空白处退出。
