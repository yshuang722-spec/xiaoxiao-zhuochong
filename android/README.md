# 小小桌宠 安卓手机版

## 使用步骤

1. 安装“小小桌宠-安卓完整版.apk”，可直接覆盖本机基础体验版。
2. 打开“小小桌宠”，在系统设置允许本应用悬浮显示，并允许通知。
3. 点击“全部开启”，或在每个角色的卡片上单独点击“显示”。离开控制页，角色会显示在其他应用上层。
4. 拖动角色可移动，慢拖松手会停在放下的位置；快速拖动并松手会甩出弹跳，此功能默认开启，可在设置中关闭；轻点播放点击回应。长按可选择动作、对话、大小和隐藏。
5. “管理→角色资料”可重命名和编辑人设，保存后用于之后的对话；同角色分身共用资料。应用内不再提供动作点播，离开应用后长按角色选择动作；“管理”可调大小、开关轮播、添加和管理分身。每个角色最多添加8个分身，原角色不占名额。手机同时播放大量分身的能力取决于硬件，不保证45个实例同时流畅运行。
6. 在“设置 → AI 接口设置”填写 HTTPS 地址、模型和 Key；根据服务商要求选择是否使用 api-key 请求头。点击“测试连接”可发送一条简短消息，以真实模型回复验证接口，确认后点击“保存”。五角色共用接口，各自保留独立人设和聊天记录。聊天窗口不会在回复后关闭，右上角 × 结束。
7. 在“设置 → 弹动与碰撞”分别选择快速甩动时弹动、角色互相碰撞，勾选即保存；“设置”还可以导出运行日志。日志按角色记录，每天每角色最多1MB，自动清理超过十天的旧日志。
8. 不需要时，点击“全部隐藏”，也可在常驻通知中全部隐藏。

### 外观与手机权限

- 在“设置”的外观分段按钮中直接选择“跟随系统”“日间模式”或“夜间模式”。选择会保存；手动模式不随手机主题改变，跟随系统则自动切换。
- 首页设置按钮左侧显示 Artemis Logo：日间用白底版，夜间用深底版。Logo 为正方形，与设置按钮等高；点按可直接切换日间／夜间并保存为手动模式，自动跟随仍可在外观设置中选择。
- 在“设置 → 手机权限”查看“悬浮显示”“运行通知”“不受电池优化限制”三个开关。开关显示系统真实状态，点击后进入相应的手机设置，返回应用后自动刷新。
- 系统权限需要在手机设置中确认。部分手机会先打开应用列表，需要再选“小小桌宠”；电池优化入口也可能是列表页。电池优化豁免与厂商的“自启动”是不同设置。
- 长按角色打开的动作面板已缩小，列表在内部滚动，分类切换保持位置。选择“对话”后只显示小输入栏，当前回复直接出现在角色气泡中，聊天时不会自动消失；发送下一句会替换上一条气泡，关闭对话会清除气泡。
- 输入框与发送按钮在同一行。想专心聊天或查看记录时，点击客户端角色卡片上的“对话”，进入大聊天页；键盘展开时自动调整阅读区域。当前每个角色保留最近100条消息。
- 记录页按“你：”“她：”紧凑排列，每条消息之间只换一行，不插入空白行或额外行距；气泡也使用紧凑行距。消息本身的原始内容仍正常保存。

本次操作调整：

- 分身列表可直接逐个显示、隐藏、调整、删除；删除后仍留在列表，点“关闭”才退出。
- 长按角色先在旁边显示“对话、动作、大小、隐藏”四项菜单；点击空白处关闭。详细动作分类进入可滚动面板，选中后关闭并播放。大小滑动条可即时预览，点“完成”保存，取消则恢复原大小和位置。
- 人物可拖到真实屏幕四边，移动范围按人物可见部分计算，系统状态栏和手势条仍由安卓管理。
- 动作列表不显示内部的余额、工作状态事件；碎碎念动画通过中文“对话动作”查看。

## 常见问题

- **角色没有出现：**检查悬浮权限，返回控制页再点击显示。控制页在前台时会暂时收起悬浮显示，离开后恢复。
- **后台被系统结束：**在手机系统中允许本应用后台运行；本版不会绕过系统限制。重新打开应用会恢复之前保存的角色状态。
- **动作不一样多：**本次按当前角色配置导入143段视频：蓝毛102、大小姐19、黄毛8、白毛10、狐狸4；类别中同一动作可以重复引用，不代表有多个视频副本。
- **有一点点边缘差别：**手机素材采用 H.264 旁路 alpha 合成，经过压缩，不能保证与原始 WebM 像素完全一致。视频静音；“送情书”等画面内特写保留。
- **聊天失败或很慢：**检查地址、认证方式、模型、网络和额度；请求最大等待60秒。填写 `/v1` 基础地址或完整 `/chat/completions` 地址均可。实际模型调用需由用户配置后验证，本次没有复制电脑上的 Key 或调用付费接口。
- **位置或大小：**每个实例独立保存，重新打开可恢复。手机横竖屏或分辨率改变时会将位置限制回屏内。
- **更新：**本版通过 GitHub 发布，暂不支持自动更新。后续版本请下载同一项目发布的 APK 覆盖安装，需保持签名一致。

## 源码与构建

`src/`：原生 Java 控制页、悬浮服务、碰撞、日志、聊天、OpenGL 透明播放器。`MotionEngine.java` 按质量与相对速度计算冲量，跟随屏幕刷新、以小步长求解，每帧合并窗口位置提交。`assets/catalog.json` 是独立角色目录；`assets/<角色ID>/` 为手机专用成品素材。

`prepare.py` 在电脑上转换素材；`measure-bounds.py` 计算每段动画的可见范围，减少透明空白拦截触摸。它们不会进入 APK。基础版已经实测的十段对齐素材被保留，其余素材保留当前桌面版的原有画面与比例。没有对所有动作重做统一放大、首尾混合或改写特写。

编译使用 JDK17、Android SDK34、Build Tools36，运行 `build.ps1`。脚本当前沿用同级 `android-lite/tools` 中的本地 JDK与测试签名；移到其他电脑时需配置这些路径。源码压缩包不包含 JDK、SDK、签名密钥、历史安装包或临时测试组件。`tests/com/xiaoxiao/pet/MotionEngineTest.java` 是电脑端的物理回归，不进入用户安装包。

本版未完成所有机型的长期后台、耗电与大量分身压力测试。用户已自行确认 API 连通；本次界面与资料验证不重复发起模型请求。构建步骤见 BUILD.md。

### 统一开关与毛玻璃试用

- “设置→弹动与碰撞”的两项使用与“手机权限”相同的开关卡片样式，可分别开启、关闭，即选即保存。
- 设置中新增“毛玻璃效果”开关，默认开启。主页、设置、管理、角色资料、应用内聊天，以及外部菜单、输入栏和气泡统一使用玻璃材质；关闭后恢复实色底。
- 文字和开关本身保持清晰。Android 12及以上且系统允许窗口模糊时使用系统接口；不可用时统一回退实色。模糊强度已提高、底色更通透；前景文字和角色视频不做模糊。兼容分支仍需要其他机型实测。
长按角色的四项快捷选项采用独立圆角设计；详细动作分类与动作项同样为圆角按钮。
列表滚动：保留系统惯性滑动，顶部/底部拖动带阻尼回弹，快速滑到底有轻微收势。关闭系统动画时不播放回弹；不影响角色物理弹动。

玻璃视觉更新：降低底色不透明度，增加细薄的圆角边缘高光。启动时直接读取已保存的显示状态，恢复服务后仅更新状态，不再重新搭建整页。动作点播不再显示底部“正在播放”提示。

界面过渡：设置、管理、资料、聊天和角色旁面板使用统一的窗口级淡入/淡出与轻微缩放，系统关闭动画时遵循系统选择。外观选择取消三项外围的额外套圈，仅突出选中项。主页单独降低白色/深色底层的不透明度，使手机原壁纸的模糊透色更明显。

动作稳定性修正：角色视频使用固定尺寸的透明画布，界面裁切不再直接缩放上一帧视频；统一画布与窗口的像素取整，清除过期裁切请求。Android 14及以上关闭角色窗口和气泡的系统位置过渡，角色弹动仍由原物理引擎控制，设置弹窗的淡入淡出保留。本机已核验代表动作结束回到待机；其他机型与长期运行仍需持续验证。
